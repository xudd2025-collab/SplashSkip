# 开屏助手 · SplashSkip

Android 开屏广告跳过助手：普通应用通过无障碍控件寻找“跳过”，已适配的特殊应用可使用本机模型和界面特征识别。画面和诊断记录不上传。

当前版本：**v0.5.2**。项目仓库：[xudd2025-collab/SplashSkip](https://github.com/xudd2025-collab/SplashSkip)。安装包见 [正式 Releases](https://github.com/xudd2025-collab/SplashSkip/releases)。原创代码和二次元小猫头像使用 [Apache-2.0](LICENSE)，第三方依赖保留各自许可。

## 功能

- 自动跳过与严格识别，可独立开关。
- AI 强化模式统一管理特殊应用适配库，目前包含百度地图和哔哩哔哩规则。
- B站视频推广卡片关闭；“取消自动进直播”是独立开关，新安装默认关闭。
- 应用启动后 6 秒防摇一摇，需要本机无线 ADB 或已授权的 Shizuku。
- 应用内无线配对、保存授权、恢复连接和手填端口。
- 从固定官方 GitHub 仓库的正式 Releases 检查更新，不支持自定义更新源。启动检查每天最多一次，可关闭；下载和安装由用户决定。
- 首页、连接、记录三页；功能名后的问号打开介绍，顶部显示实际 APK 版本。

## 使用

1. 安装 APK，在系统设置中开启“开屏助手”的无障碍服务。
2. 普通跳过无需无线 ADB。需要防摇一摇时，在“连接”页完成首次无线配对。
3. Android 11 及以上：连接 Wi-Fi，开启开发者选项。点“开始首次配对”进入系统无线调试，开启后打开“使用配对码配对设备”。
4. 保持系统配对窗口打开，下拉助手通知，输入系统显示的 6 位码。本应用只连接 `127.0.0.1`，授权密钥保存在应用私有目录且不参与备份。
5. 以后点击“恢复连接”会再次打开无线调试页，开启无线调试后返回助手，立即使用保存授权恢复。授权已被撤销时，通过“无线配对”重新授权。

部分系统只能打开开发者选项，需要再点“无线调试”。搜索不到时填无线调试首页的**连接端口**；首次手动配对使用配对窗口的**配对端口**和 6 位码，两种端口不同。端口搜索最多 6 秒，配对等待最多 3 分钟。

## 兼容与范围

- APK 最低 Android 8；本机无线配对需要 Android 11。旧系统可使用已运行的 Shizuku 兼容入口。
- 原生库包含 arm64-v8a、armeabi-v7a、x86 和 x86_64。厂商后台管理、无障碍控件和传感器命令存在差异，不能承诺所有机型都生效。
- 模型是电脑训练的 32 × 20 灰度跳过文字分类器，结合已知候选区域使用，**不是任意位置的通用 OCR**。未知布局需补充适配。
- NNAPI 不可用时退回 CPU；委托成功不代表已经确认使用物理 NPU。
- 百度地图适配已采集的长胶囊、白色圆形、小胶囊跳过按钮与一类首页活动弹窗；B站适配已提供的广告卡片与自动进直播预览样式。
- 跳过文字需连续两帧稳定识别，点击前确认前台、开关、锁屏和截图时效。提交点击与点击后检查分别记录；目标消失不能证明所有广告都有效。
- 防摇一摇暂停目标应用的运动传感器，指南针和重力感应也会暂停 6 秒。独立 shell 定时恢复；设备不支持或未连接时不会生效。

## 构建与检查

需要 JDK 17、Android SDK Platform 36 和 Build Tools 36.0.0：

```powershell
./tools/check.ps1 -JavaHome C:\path\to\jdk-17
./build.ps1 -SdkPath C:\path\to\android-sdk -JavaHome C:\path\to\jdk-17
```

生成 `app-debug.apk`。版本统一修改 `version.properties`。覆盖更新必须保持签名一致；`.build/debug.keystore` 不能随源码公开。固定发布签名流程见 [OPEN_SOURCE.md](OPEN_SOURCE.md)。

`tools/check.ps1` 可传 `-AdScreenshot` 与 `-LiveScreenshot`，使用外部已脱敏截图验证生产匹配器的缩放和负样本。模型训练代码与数据格式见 [tools/model_training.md](tools/model_training.md)；原始个人采集数据不公开。
