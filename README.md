# 开屏助手 · SplashSkip

开屏助手（SplashSkip）是一款安卓开屏广告跳过与广告自动关闭工具。结合当前无障碍控件的父子关系、离线文字识别和按钮特征，寻找“跳过 / 关闭广告”等操作，再核对当前页面后执行模拟点击。

**最新正式版：v0.6.50** · [正式 APK](https://github.com/xudd2025-collab/SplashSkip/releases/latest) · [更新说明](RELEASE_NOTES.md)

由 **xudd2025-collab** 独立维护，官方免费发布，请勿付费购买。自 v0.6.32 起，原创部分采用[源码可用许可](LICENSE)，禁止未经许可售卖，分发须保留作者、官方源码及应用内“查看源码”入口。此许可不属于 OSI 标准开源许可；已发布的 Apache-2.0 旧版及第三方组件保留原授权。

## 功能

- **自动跳过**：在后台读取当前父子控件，核对可点击祖先后执行原生点击。默认不截图；只有手动开启“视觉补充识别”后，才在控件不足时使用当前画面。
- **AI 强化**：内置 PP-OCRv4 文字检测和中文识别，结合动作文字、广告语境、按钮边界与遮挡情况判断。通用入口支持未登记的可启动应用，特殊页面另有规则。
- **应用规则**：集中管理哔哩哔哩、百度地图、百度网盘、虎牙、腾讯视频、中国移动等已适配场景。B站取消自动进直播单独开关。
- **虎牙直播广告（待验证）**：已加入同卡片“倒计时＋关闭”、图片白色叉号及横竖屏识别策略；完整实机测试尚未完成。
- **6 秒防摇一摇**：应用启动或从后台切回后重新计时，通过已授权的本机无线 ADB 或 Shizuku 暂停运动传感器，到期恢复。
- **连接恢复**：应用内配对、一键恢复、手填端口和可选 Wi-Fi 自动连接；连接页显示系统无线调试状态，配对引导随开关状态更新，不支持直达入口的系统提供开发者选项引导。
- **应用内更新**：打开或返回前台时检查本仓库正式 Releases，30 秒内重复返回不重复请求；发现新版在右上角显示“有更新”，点击即可查看。可关闭弹窗提醒，角标与手动检查仍可使用。在应用内下载、续传、校验后调起系统安装。
- **自动控件边框**：打开其他应用时自动记录控件图、父子关系、类名、资源 ID 和识别结果，回到助手仍可查看和导出。全屏查看支持可点击/动作筛选、编号列表、缩放、重叠框切换和父子节点；显示系统可点击属性、点击父级与中文扫描结果。默认开启，本机保留最多 64 条、7 天、约 1.5 MB；部分树与独立广告区域明确标注。只用于诊断，不按历史边框点击。
- **本地记录**：查看点击过程、按钮特征及控件与视觉联合记录，支持纠正、清除和主动导出，提供[电脑控件检查器](tools/desktop-capture/README.md)及训练工具。

更新加速使用第三方公共转发线路，默认开启、可关闭；它们并非项目运营的官方国内镜像。网络可用性和下载速度受线路影响，不保证每次可达。安装前检查大小、SHA-256、包名、版本与当前 APK 签名。

## 安装与使用

1. 从[正式 Releases](https://github.com/xudd2025-collab/SplashSkip/releases) 下载 APK；已有官方版本可覆盖安装。
2. 阅读首次使用须知，在系统设置开启“开屏助手”无障碍服务。普通覆盖更新不重复要求确认须知。
3. 在“应用规则”里选择希望处理的场景。“视觉补充识别”默认关闭；自绘广告未暴露按钮时，纯控件模式可能无法跳过。
4. 需要防摇一摇时，在“连接”页完成无线配对，或使用已授权的 Shizuku。

Android 11 起支持本机无线配对。首次配对使用配对窗口的端口和 6 位码；恢复连接使用无线调试首页的连接端口。通知绑定当次配对窗口的端口与会话，关闭或重新打开窗口后使用新通知和新码；应用重启清除旧通知。首次配对、系统网络确认与被撤销的授权仍需本人操作。

“Wi-Fi 自动连接”默认关闭。启用后，助手通过已配对连接申请一次 WRITE_SECURE_SETTINGS，用于自动开启 TLS 无线调试并恢复连接。自动失败时，可手动开启后返回助手。厂商结束应用进程后可能需要重新打开。

## 识别与兼容范围

- APK 最低 Android 8；视觉截图能力受 Android 版本与系统限制，本机无线配对要求 Android 11。包含 arm64-v8a、armeabi-v7a、x86、x86_64 原生库，主要实机验证来自 vivo V2509A / Android 16。
- 当前按钮、文字、父子关系及页面语境决定是否点击。近期特征与模型只帮助判断当前候选，不能凭历史坐标盲点；通用 OCR 不要求记住广告商品图片。
- 控件移动或分辨率变化时重新定位。仍可能漏识别、识别慢或误判，无法保证所有应用、所有样式或 1 秒内完成。普通推荐、静音叉号和不明确的目标可能被保守跳过。
- Android 未暴露的自绘元素可能没有可读取的父子节点，电脑采集也受此限制。视觉观测与原生树分别保存，不伪造原生节点。
- OCR 在本机 CPU 运行；旧 TFLite 路径可尝试 NNAPI，未确认使用物理 NPU。
- 高频识别集中在短时前台扫描窗口。纯控件模式不请求截图、不初始化 OCR；开启视觉补充后，桌面、后台和锁屏仍不截图。部分独立弹窗规则有额外前台检查条件，耗电因应用而异。
- 防摇一摇会同时影响指南针等运动传感器功能；需要有效连接及系统支持。

模拟点击不修改目标软件数据。请自行评估目标应用规则和账号风险；开发者不承担相关责任，依法不得免除的责任除外。详情见应用内使用须知及 [LICENSE](LICENSE)。

## 构建与检查

需要 JDK 17、Android SDK Platform 36、Build Tools 36.0.0，Windows PowerShell：

```powershell
./tools/check.ps1 -JavaHome C:\path\to\jdk-17
./build.ps1 -SdkPath C:\path\to\android-sdk -JavaHome C:\path\to\jdk-17
```

配对会话与 NSD 回调的独立检查：`python tools/check_pairing.py --java-home C:\path\to\jdk-17`。覆盖旧通知、窗口更换、迟到解析、串行解析和解析占用重试。

生成 app-debug.apk，版本统一读取 version.properties。覆盖安装须沿用原签名；签名私钥不公开。固定签名及源码打包见 [OPEN_SOURCE.md](OPEN_SOURCE.md)。

训练与评估见[模型训练](tools/model_training.md)、[联合记录训练](tools/joint_learning.md)和[电脑控件检查器](tools/desktop-capture/README.md)。个人原始截图和采集日志不发布；缺少原始数据时无法复现完全相同的训练权重。
