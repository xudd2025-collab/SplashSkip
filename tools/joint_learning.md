# 控件树与视觉联合学习（本地）

## 当前实现

v0.6.23 从当前应用的无障碍树读取至多 128 个节点、18 层，读取循环预算 30 ms（单次系统调用仍可能超时）。仅保留动作/广告/导航类别，控件资源 ID 和类名立即转换为 SHA-256 摘要。查找最近 4 级可点击祖先，拒绝整幅广告或不包含按钮的父容器。

当前树提供候选区域，本机 PP-OCRv4 对区域及广告线索进行视觉核对。普通“关闭”的快速路径要求完整控件树、明确动作文字、尺寸合理的可点击祖先、启动窗口、没有导航节点，以及当前视觉广告语境；否则继续完整场景检查。若控件没有文字，可通过本机确认成功的结构摘要提出当前节点。历史模板绝不返回坐标。过期树、其他包、旋转后的树不使用；缺树或核对失败回退全屏视觉。点击前仍重新截图核对、检查浮层，开屏提交一次后不盲目补点。

## 记录

入口：**记录 → 控件与视觉特征库**。联合数据默认本机记录，可关闭、逐条纠正、清除、用系统文件保存入口导出。最多 256 条、30 天；应用私有 `joint-controls.json`，不自动上传。

每条：随机记录 ID、应用包名、时间、版本、动作、结构摘要、12 个关系/尺寸特征、8×8 按钮灰度特征、结果和来源。没有完整截图、广告正文、原始资源 ID、历史坐标。即便关闭记录，当前控件树仍可用于定位。

未能形成安全点击决策时，每个场景中每种明确控件结构最多保留一个未点击候选（每场景最多 8 种）。`attempted=false`、`source=tree_observation`，仅用于分析漏识别，不能手动标成点击成功，也不进入训练。这样可以记录失败线索，同时保持监督标签准确。

- `unknown`：默认值，包括中断、画面不全、被挡住、应用切换，**不参与训练**。
- `success` / `two_clear_frames`：完成手势后两个新鲜、清晰、同应用画面独立确认原控件消失，是观察证据，不能保证因果关系。允许用户纠正。
- `no_effect` / `two_present_frames`：完成动作后至少 400 ms，两个相隔至少 180 ms 的清晰画面仍有同一按钮。
- `mistouch`：只能由用户主动纠正。
- `source=user`：用户查看对应应用/时间/动作后确认；自动结果不覆盖用户纠正。

“记录手动点击”会暂缓自动点击，最多两分钟，关联新鲜的点击前候选与控件点击事件。成功配对仍标 `unknown`，需要用户确认结果。未提供事件、没有点击前样本或多个候选不明确时，只保留诊断事件，不伪造训练样本。

## 电脑统一训练

```powershell
python tools/train_joint_controls.py export1.json export2.json --output training/joint-run
```

纯 Python 标准库的 L2 正则逻辑回归，输入 76 维。它学习候选优先顺序，不代替 OCR、广告语境、新鲜度或浮层门槛。按应用分组保留验证集，不让同一应用截图或增强图跨训练/验证。重复记录、矛盾标签、未知结果剔除。

至少 40 条有效标注、4 个应用、正负各 10 条；训练/验证都需正负样本，验证正负各至少 5 条且 AUC ≥0.8 才输出 `joint_control.properties`。否则只输出待收集/未通过报告。通过后将文件复制到 `app/src/main/assets/joint_control.properties` 并重新构建；端侧检查 schema/维数/有限权重/validated 标志。保留已验证模型，不用验证数据重训。

旧截图仍可用于视觉回归，但不包含父子控件树，不能拼造结构数据。本版没有足够真实联合标注，**尚未生成新训练权重**，使用通用 OCR 和已确认的本机结构记忆。未启用新的 NPU 后端。

电脑复核录屏可用 `review_joint_record.py` 对导出文件副本标注。必须指定唯一记录 ID、含该 ID 的诊断日志、对应视频和复核说明；输出 `source=recording_review` 及两个证据文件的 SHA-256。不修改手机标签。复核者仍需亲自核对视频，工具只验证关联格式；未点击候选即使被误标为成功也不会进入训练。

## 验证

`JointControlCheck`：移动/缩放、父容器限制、包/epoch/时效、旋转、元数据复制、局部特征、成功/无效门槛、未验证模型拒绝。

`python tools/check_joint_training.py`：未知标签、矛盾记录、重复导出、样本不足、应用分组和权重输出；所有合成样本只用于契约测试，临时目录自动删除。

手机真机延迟需另行记录截图请求到手势完成；这些离线检查不证明全流程 1 秒目标，也不保证识别所有自绘控件。
